LEAPS（到期 ≥ 1 年的长期期权）是期权交易中最被低估的工具之一。选对了，它几乎就是"打折买正股 + 少量租金"——用 40-70% 的资金锁定 90-99% 的涨跌幅。

这篇文章整理了一套系统化的深度 ITM LEAPS 筛选框架，附带实战数据和代码。

---

## 一、什么是深度 ITM LEAPS CALL？

| 对比维度 | 正股 | 深度 ITM LEAPS CALL |
|:--|:--|:--|
| 资金占用 | 100% 股价 | 40-70% 股价 |
| Delta 敞口 | 1.00 | 0.85-0.99 |
| 股息 | ✅ | ❌（已隐含在定价中） |
| 最大损失 | 全部本金 | 全部权利金 |
| 时间损耗 | 无 | 极少（外在价值极低） |

核心逻辑：深度 ITM CALL 的价格 ≈ 内在价值（正股价 − 行权价），只有极少部分是"时间的租金"。你释放出的现金可以买货币基金赚利息，进一步抵消那一点点时间成本。

---

## 二、五维筛选指标体系

| # | 指标 | 默认阈值 | 为什么 |
|:--|:--|:--|:--|
| ① | **Delta** | > 0.80 | 衡量对正股变动的敏感度。0.85 意味着正股涨 $1，期权涨 $0.85 |
| ② | **IV (隐含波动率)** | < 50% | IV 越低，期权越便宜。低 IV 买入 = 成本更低 |
| ③ | **OI (未平仓量)** | > 100 | 流动性指标。OI 高 = 做市商活跃 = 买卖价差小 |
| ④ | **外在价值占比** | < 10% | (期权价 − 内在价值) / 期权价。越低越接近纯正股替代 |
| ⑤ | **资金占比** | < 50% | 期权价 / 正股价。衡量用多少资金获得近似敞口 |

### ④ 和 ⑤ 的核心公式

```
内在价值 = max(0, 正股价 − 行权价)     ← CALL 的方向
外在价值 = 期权价格 − 内在价值          ← 你为"时间"付的钱
外在占比 = 外在价值 / 期权价格 × 100%
资金占比 = 期权价格 / 正股价 × 100%     ← 杠杆率 = 1 / 资金占比
```

### 一个直观例子（AAPL $289）

| 合约 | 行权价 | 期权价 | 内在价值 | 外在价值 | 外在% | 资金% |
|:--|--:|--:|--:|--:|--:|--:|
| 271217 100C | $100 | $189.83 | $189.36 | $0.47 | **0.2%** | 65.6% |
| 270617 150C | $150 | $140.06 | $139.36 | $0.70 | **0.5%** | **48.4%** |
| 270617 190C | $190 | $110.25 | $99.36 | $10.89 | **9.9%** | 38.1% |

注意：100C 外在占比最低(0.2%)但资金占比最高(65.6%)；190C 资金占比最低但外在占比边缘(9.9%)。**150C 在两者间取得了最佳平衡**。

## 三、不同股票 IV 差异与阈值调整

不是所有股票都适合 LEAPS。IV 是分水岭：

| 股票类型 | IV 典型区间 | 建议 IV 阈值 | LEAPS 适合度 |
|:--|:--|:--|:--|
| 低波动蓝筹（AAPL/MSFT） | 25-50% | 50% | 🟢 非常适合 |
| 中等波动（NVDA） | 50-80% | 70% | 🟡 放宽可用 |
| 高波动（TSLA） | 70-120% | 90% | 🟠 勉强 |
| 极高波动（MU/SPCX/MSTR） | 120%+ | — | 🔴 不建议 |

## 五、实战工作流

### Step 1：确认标的
选择愿意长持 1-3 年的正股，优先低 IV 蓝筹。

### Step 2：拉取 LEAPS 到期日 + 期权链 + 快照
用富途 API 批量获取 Delta / IV / OI / 价格数据。

### Step 3：五维过滤
```
Delta > 0.80 → IV < 阈值 → OI > 100 → 外在 < 10% → 资金占比 < 阈值
```

### Step 4：横向对比 + RSI 择时入场
- 同正股不同到期日：选 OI 高 + 外在低
- RSI < 30 超卖区建仓最佳
- 限价单，无需追涨

## 六、风控与退出

| 场景 | 策略 |
|:--|:--|
| 正股大涨 | ✅ 期权同步涨，可持有到期行权或卖出 |
| 正股横盘 | ⚠️ 外在价值缓慢衰减，但深度 ITM 年化损耗极小 |
| 正股大跌 | 🔴 Delta 0.9 = 跌 $1 亏 $0.9。需要止损纪律 |
| 临近到期 | 提前 3-6 个月决定：滚动（卖旧买新）还是行权接正股 |

### 最大风险

**Delta 高 ≠ 无风险。** 深度 ITM CALL 本质是加杠杆的正股替代——正股腰斩，你的 LEAPS 也接近腰斩。它不是避风港，是节省资金的工具。

## 总结

| 关键原则 | 一句话 |
|:--|:--|
| 选标的 | 长期看好的低 IV 蓝筹 |
| 选 Delta | 0.85-0.95，够像正股又不溢价太多 |
| 选 IV | 低于该股历史中位数 |
| 选流动性 | OI > 100，大额 > 500 |
| 选行权价 | 在资金占比预算内选最低的行权价（外在占比最低） |
| 控制成本 | 外在价值 < 10%，< 5% 为优秀 |
| 入场时机 | RSI < 30 最佳，< 50 可建仓 |
| 资金管理 | 每张 CALL 占正股资金的 40-55% |
