卖PUT是期权交易中最经典的"时间的朋友"策略——你不需要猜股价涨跌，只需要股价**不跌到某个位子**就能稳定收钱。而**移仓（Rolling）** 是把这种收益持续滚动下去的核心操作。

这篇文章把卖PUT移仓的逻辑、操作、纪律和避坑清单一次性讲透。

---

## 一、你赚的是谁的钱？

卖出PUT时，你收取**权利金（Premium）**，这份权利金由两部分组成：

| 组成部分 | 说明 |
|---------|------|
| **内在价值** | max(行权价 - 现价, 0)，价外PUT的内在价值为 **0** |
| **时间价值** | 权利金扣除内在价值后的部分，**随到期日逼近而衰减** |

移仓获利的核心就是：**反复收割时间价值的衰减过程**。

只要你的行权价始终在股价下方（OTM），你的对手方（买PUT的人）就在持续为你交"保险费"，而时间是你最好的盟友。

---

## 二、三步走：移仓的标准流程

### Step 1：初始开仓

假设 AAPL 现价 $255，你看好它到 $405（长线持有逻辑不变）：

```
卖 AAPL 2026-07-31 PUT, 行权价 $230, 收取权利金 $3.50/股
→ 1张合约收 $350
→ 年化收益 = (350 / 23000) × (365/30) ≈ 18.5%
```

### Step 2：移仓触发信号（三选一）

| 触发条件 | 操作 |
|----------|------|
| ⏰ **时间过半** | 剩余 ~15 天，大部分时间价值已衰减 → 移仓到更远期 |
| 💰 **浮盈达标** | 权利金已赚到 70-80%，提前平仓锁利 → 开新仓 |
| ⚠️ **股价逼近行权价** | 立即移仓到下月 + 更低行权价 → **这是关键风控** |

### Step 3：执行移仓

```
平仓：买入平仓 AAPL 2026-07-31 $230 PUT，花 $1.20（浮盈 $2.30）
开仓：卖出开仓 AAPL 2026-08-28 $235 PUT，收 $4.80
→ 净权利金流入 = $4.80 - $1.20 = +$3.60
→ 行权价同步上移（从 230 → 235），顺势而为
```

## 三、四条铁律：稳定获利的核心纪律

### 3.1 选对标的

> **只卖你愿意持有正股的标的。** 这是卖PUT的第一性原理。

- 基本面强、波动率适中的大盘股（AAPL / NVDA / GOOGL 都适合）
- 如果股价跌到行权价，**你是真的愿意接货的**
- 避免财报前开仓——IV crush 会伤害卖方

### 3.2 行权价的安全边际

```
行权价 ≤ 现价 × 0.85 ~ 0.92  （即 OTM 8-15%）
```

- AAPL $255 现价 → 卖 $220–235 的 PUT
- **永远不要卖 ATM（平值）PUT** 来移仓——那是赌博，不是策略

### 3.3 黄金到期区间

**30–45 DTE（Days to Expiration）** 是最优窗口：

- < 14 天：Gamma 风险暴增，股价小波动导致权利金剧烈摇摆
- > 60 天：Theta 衰减太慢，资金被长期占用，效率低
- 30–45 天：Theta 衰减最快段 + Gamma 可控 = **甜点区**

### 3.4 移仓时机（最重要的纪律！）

```
黄金窗口：剩余 15–21 天
```

| DTE | Theta 衰减 | 操作建议 |
|-----|-----------|---------|
| 60  | 极慢 | 持有等待 |
| 45  | 加速 | 持有 |
| 30  | 明显加速 | 观察 |
| **21** | — | **← 最佳移仓点** |
| 14  | Gamma 陡升 | 危险，尽快行动 |
| 7   | 爆炸性 Gamma | 权利金吃干但风险极大 |
| 0   | — | 到期 |

**在 21 天左右移仓，你既吃到了 70% 以上的时间价值，又完美避开了 Gamma 风险。**

## 四、四象限情景决策框架

|  | 🟢 股价远离行权价 | 🔴 股价接近/跌破行权价 |
|---|---|---|
| **剩余 >30 天** | 继续持有 | 评估移仓到更远 + 更低行权价 |
| **剩余 <21 天** | 移仓到 30-45 天，顺势提高行权价 | **紧急移仓！滚到 45 天 + 更低行权价** |

## 五、真实数学：12 个月滚动复利

假设每月移仓一次，每次年化收益 12–20%：

| 月 | 权利金 | 累计 | 现金担保金（$230 行权价×100） |
|----|-------|------|------------------------------|
| 1  | $350  | $350  | $23,000 |
| 2  | $320  | $670  | $23,050 |
| 3  | $340  | $1,010 | $23,150 |
| …  | …     | …     | … |
| 12 | $310  | **~$3,800** | $23,700 |

**年化收益 ≈ $3,800 / $23,000 ≈ 16.5%**

这不是一个月的偶然，而是**可以稳定复制的年化收益**。核心在于纪律执行，而非预测市场。

## 六、五个要命的坑 ⚠️

| 坑 | 为什么危险 | 怎么避免 |
|----|-----------|---------|
| 🚫 **财报前卖PUT** | IV 虚高看似诱人，但股价可能跳空暴跌 | 财报前后 3 天不开新仓 |
| 🚫 **越跌越卖** | 跌了就加卖 PUT → 被行权后浮亏滚雪球 | 跌穿支撑位就停止移仓，接受行权 |
| 🚫 **行权价追涨** | 涨了就把行权价大幅拉升 → 失去安全边际 | 行权价上调 < 股价涨幅的 50% |
| 🚫 **过度杠杆** | 卖 PUT 占满所有保证金，没有余量 | 现金担保占用 ≤ 总资金的 60% |
| 🚫 **不设止损** | 崩盘时死扛不放 → 权利金翻倍还在等 | PUT 权利金翻倍时立即平仓止损 |

---

## 七、总结：稳定获利的公式

```
稳定获利 = 选好标的（你愿意持有）
         + 30–45 DTE（吃 Theta 最快段）
         + OTM 8–15%（安全边际）
         + 15–21 天移仓（吃到 70% Theta 就换）
         + 顺势微调行权价（涨就上移，跌就下移/暂停）
         + 不用杠杆（现金担保充足）
         + 年化 ≥ 10% 才做（筛选标准）
```

---

> **卖PUT的本质不是"赌股价不跌"，而是"我愿意在这个价格买它"——如果你真的愿意持有它，那无论行权还是滚动收租，你都是赢家。**
